### 補足

^1「顔感情分析-セットアップボタン」

セットアップボタンは４つの状態を持たせる

1. 未設定-> unset

灰色 + バツマーク

2. キャリブレーション中 -> now_setting

ぐるぐるしたロード中のくるくるを表示

3. 設定済み-> pass_settings

再実行のアイコンを緑で入れて、セットアップが再度実行できるようにしておく

4. 設定エラー -> error

再実行のアイコンを赤で入れて、セットアップ横にあるテキストに何が原因でエラーが発生したかを記入させる
これを本日初回起動時に行いたいですよと
